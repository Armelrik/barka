# Présentation client

La présentation publique fonctionne en mode `CATALOG_MODE=demo`, sans base de données. Les annonces et prix sont fictifs ; les images d’illustration proviennent de l’ancien projet Afriloc. La charte orange et turquoise est conservée.

Parcours conseillé :

1. `/` : accueil, sélection de biens, favoris et navigation.
2. `/biens` : huit annonces, filtres par projet, quartier, type et budget. Faire défiler les photos d’une carte avec les flèches ou un geste horizontal sur mobile.
3. Ouvrir une fiche : galerie, description personnalisée, caractéristiques et prix.
4. Sur la fiche, proposer un horaire dans « Organiser une visite » : le formulaire montre une simulation explicite, sans envoi ni rendez-vous réel.
5. `/visites/demo` : passer du salon à la cuisine, lancer la visite guidée, afficher le plan puis le modèle 3D. La scène est une démonstration géométrique, sans lien avec un logement réel.
6. `/carte` : huit localisations fictives, avec accès aux fiches, à Ouagadougou et Bobo-Dioulasso.
7. Refaire le parcours sur téléphone : menu, favoris, galerie et visite tactile.

Pour les dossiers réels, l’espace de gestion nécessite une base migrée et un stockage de médias configuré. Voir [property-management.md](property-management.md). La réservation, les paiements, l’envoi du formulaire de contact et la newsletter ne font pas partie de cette démonstration fonctionnelle.

Le lien public temporaire est servi depuis ce Mac : le PC doit rester allumé, connecté et le serveur de prévisualisation actif. Ce lien ne remplace pas un hébergement permanent.
